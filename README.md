# Football Pick Ems — full dashboard

This version includes:
- current week selected automatically
- weekly standings
- overall season standings
- picks matrix
- correct / incorrect / pending pick styling
- First Name + Last Initial public names only

## Privacy boundary

GitHub Pages and the browser are public.

The Apps Script API uses phone numbers and full names only inside Google to calculate results.
The public JSON is constructed from an explicit whitelist and contains no phone numbers,
emails, timestamps, raw responses, private IDs, Sheet IDs, or full participant records.

Before deploying a new Apps Script version, run `testPublicOutput()` and inspect the log.
